# 上班啟示錄：打卡衝衝衝（v0.1.0）

《上班啟示錄》同一批角色做的**橫向捲軸無盡跑酷**。小葵 08:59 快遲到了，自動往右跑、一路衝上樓打卡；撞到一次特助 Kevin 會踩著 AI 平衡車追上來，追的這 9 秒內再撞到就被抓去開會（遊戲結束）。

- 只有「跳」和「滑壘」（使用者 2026-10-22 選了「純跑酷」，不做揍人）。
- 不做登入、儲值、等時間、社交；只存最佳距離（localStorage）。

## 怎麼玩
| | 手機 | 電腦 |
|---|---|---|
| 跳 | 點右半邊（按住跳更高、空中再點＝二段跳翻一圈） | 空白鍵／↑／W |
| 滑壘 | 點左半邊（按住滑久一點；空中按＝快速落地接滑壘） | ↓／S |
| 暫停 | 右上 ⏸ | P／Esc |

- 障礙：影印紙堆、紙箱「急件」、打翻的咖啡（要跳過）、自己滑過來的辦公椅、AI 機器人（可以踩扁 +3）、AI 無人機與「這個用AI就好了」紅布條（要滑過去）、辦公桌（可以跳上去跑，腳快到桌面會自動踩上去，貼地撞側面才算撞）。
- 收集：鈔票、☕ 咖啡（衝刺無敵 3.2 秒、撞飛障礙、吸鈔票）、🪪 員工證（擋一次）。
- 每 240 m 一區、終點有打卡鐘（+20）：1F 大廳 → 3F 開放辦公區 → 5F 茶水間 → 8F 老闆樓層 → 11F…一直循環、越跑越快。
- 名角色客串：大廳小米「小葵早安！衝啊☕」、辦公區阿傑「我先下班囉～」、老闆樓層 Vivi「辛苦了！加油！（沒有加薪）」。背景還有上班族男女走來走去。

## 本機預覽
`.claude/launch.json` 的 `office-sidescroller`（port 4450，`tools/serve.py` 不快取）。
- 網址加 `?play` 跳過封面直接開跑；`?bot` 自動玩。
- 測試：`window.G`（`G.hold=true` 停掉 rAF 自己推進、`G.step(dt, n)`、`G.bot`、`G.start()`、`G.kevinCome()`、`G.caught()`、`G.P` 小葵狀態、`G.L` 關卡）。一次 javascript_tool 別跑超過約 6000 格（會逾時、分頁被關掉）。
- 預覽視窗被藏起來時會觸發 visibilitychange 自動暫停；`G.hold=true` 時不會。

## 檔案
- `index.html`：介面（HUD、左右觸控區、封面／暫停／結算）、擋放大與選取。
- `js/main.js`：遊戲本體。**手感數值都在最上面的 `CFG`**（速度、重力、滑壘、Kevin 追幾秒、咖啡衝刺）。
- `js/level.js`：背景段（主樓層＋上下各兩層的剖面）、障礙物片段 `PATTERNS`（依難度出現）、打卡鐘。背景道具用道具池重複使用（不會一直生新貼圖）。
- `js/props.js`：障礙物、收集物、Kevin 的平衡車、打卡鐘、各區牆／地板／其他樓層的貼圖（`THEMES`）。
- `js/music.js`：程式配樂（C-Am-F-G 小調，音量小）；`fx.js` 合成音效。
- 從 `office-apocalypse/` 複製來的：`world.js`（改成側面鏡頭＋幾何體快取）、`assets.js`（改成**載入時**把走路低頭、小跑前傾烤進動畫關鍵格）、`stations.js`／`decor.js`（咖啡機、印表機、販賣機、設計桌）、`fx.js`、`models/`、`icons/`、`design/d_*.png`。**這個資料夾的修改不會影響原本的上班啟示錄。**
- `design/v0.1_*.jpg`：v0.1 截圖。

## 角色注意
- 模型臉朝 +z，側面跑要繞 y 轉 +90°（臉朝 +x）。
- 小葵用 `kui_walk2` + `kui_jog`（`loadKind(url, 7)` 扶正到前傾 7°），`forceJog=1` 永遠用小跑；空中動畫放慢 0.45、滑壘幾乎停住（`animMul`）。
- Kevin 只有走路動作，所以讓他站在 AI 平衡車上（站姿張手像在平衡），不會滑步。
